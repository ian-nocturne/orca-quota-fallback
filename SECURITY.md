# Security

Do not attach API keys, OAuth tokens, private conversation transcripts, account screenshots, or machine-specific configuration to issues or pull requests.

This development preview must remain disabled until the host can prove exclusive continuation ownership, fresh credit availability, and a provider-enforced or otherwise verified no-paid-overflow boundary. A caller-supplied boolean is not independently verified billing evidence.

Uncertain outcomes must remain held. Do not delete a ledger or stale lock merely to make a retry succeed: first reconcile whether the original dispatch executed. Keep the ledger private and outside a source repository.

If GitHub private vulnerability reporting is enabled, use that channel for sensitive reports. Otherwise submit a public issue containing only a request for a private reporting channel, with no exploit or account data.
